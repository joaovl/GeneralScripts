15. Glossary

Active/backup. Two computers running together, one in control and one ready to take over if it fails.

BSP. Board support package: the startup code, drivers and initialisation that make a bare board usable by application software.

CCDL. Cross channel data link: the cross data link in AERTEC's scope that lets the active and backup units share state and health.

HAL. Hardware abstraction layer: the documented set of functions through which application software reaches the hardware.

ICD. Interface control document: the definitive description of an interface, from physical layer to message formats and timing.

JTAG and SWD. Standard debug ports that let a debugger control the processor, set breakpoints and inspect memory.

Linker script. The file that tells the linker where code and data are placed in memory.

Memory map. The layout of all addressable memory and memory mapped devices on the board.

Toolchain. The compiler, assembler, linker and libraries that turn source code into a binary for the target processor.
